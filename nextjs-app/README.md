# file-storage-ui (Next.js)

แปลงจาก Vite + React มาเป็น **Next.js (App Router, JavaScript)** โดยยังคงฟังก์ชันการทำงานเดิมไว้ทั้งหมด พร้อมแก้ไข/เพิ่มตามที่ร้องขอ

## วิธีรัน

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

```bash
npm run build
npm run start
```

## โครงสร้างโปรเจกต์

```
app/
  layout.jsx        ครอบทั้งแอป, import globals.css
  page.jsx           หน้าเดียวที่คุมการสลับหน้า (upload / passwords / setting) เหมือน App.jsx เดิม
  globals.css        รวม CSS เดิมทั้งหมด (index.css, App.css, UploadFile.css, FilePasswords.css, Setting.css) + สไตล์ใหม่
components/
  UploadFile.jsx
  FilePasswords.jsx
  Setting.jsx
  DefaultAvatar.jsx
context/
  LanguageContext.jsx  จัดการภาษา + ข้อมูลผู้ใช้ + รหัสผ่านบัญชี (SSR-safe, อ่าน localStorage หลัง mount)
```

โปรเจกต์เดิมใช้ state ในการสลับหน้า (ไม่ใช้ URL routing) — ผมคงพฤติกรรมนี้ไว้เหมือนเดิมเพื่อไม่ให้ฟังก์ชันเปลี่ยน ถ้าต้องการ URL จริง (เช่น /passwords, /setting) แจ้งได้ เดี๋ยวแยกเป็น route ให้

## สิ่งที่แก้ไข/เพิ่มตามที่ขอ

1. **ย้ายจาก Vite → Next.js** — โครงสร้างเปลี่ยนเป็น App Router แต่หน้าตา/การทำงานเหมือนเดิมทุกอย่าง
2. **เลือกไฟล์ก่อนตั้งรหัสผ่านตอนอัปโหลด** — ตอนเปิดใช้ "File Password" ระบบจะแสดงรายการไฟล์ที่เลือกไว้ให้ติ๊กเลือกว่าจะใช้รหัสผ่านนี้กับไฟล์ไหนบ้าง (ค่าเริ่มต้นติ๊กไว้ทุกไฟล์ ผู้ใช้ปลดติ๊กไฟล์ที่ไม่ต้องการได้)
3. **หน้ารหัสผ่านไฟล์ (File Passwords) ใช้รหัสผ่านบัญชีผู้ใช้แทนรหัสผ่านของไฟล์เอง** — ตอนกดดู/เปิดไฟล์ที่มีรหัสผ่าน ระบบจะขอ "รหัสผ่านเข้าสู่ระบบ" ของผู้ใช้ (ค่าเริ่มต้นในดาต้าจำลองคือ `Password123`) แทนที่จะขอรหัสผ่านของไฟล์นั้น ๆ และรหัสผ่านนี้เปลี่ยนได้จริงที่หน้า Setting → Change Login Password
4. **ลบปุ่ม Edit Profile** — กดที่รูปโปรไฟล์ได้เลยเพื่อเลือกรูปใหม่ (มีไอคอนกล้องขึ้นตอน hover เป็นตัวบอกใบ้)
5. **หน้า Change Login Password** — ลบปุ่ม "← Back" ที่ทำงานเหมือนยกเลิกออกแล้ว และเปลี่ยนปุ่มยืนยันจาก "Confirm Change" เป็น "Confirm" (สั้นลง) พร้อมเช็ครหัสผ่านปัจจุบันจริง ๆ ก่อนเปลี่ยน
6. **แถบเมนูด้านบน** — เพิ่มปุ่ม **Home** เข้าไปอีกปุ่ม (แยกจากปุ่ม "Upload File" เดิม) ในทุกหน้า

## หมายเหตุ

- ข้อมูลทั้งหมด (ไฟล์, รหัสผ่าน, โปรไฟล์) ยังเป็น mock data ในหน่วยความจำเหมือนโปรเจกต์เดิม ยังไม่ได้ต่อ backend จริง
- แก้ไข key คำแปล (i18n) บางตัวที่ไม่ตรงกันในโค้ดเดิม (เช่น `maxFilesMessage`, `passwordIncorrect`, `saveProfileMsg` ฯลฯ) ให้ตรงกันแล้ว ไม่งั้นบางข้อความจะโชว์เป็นชื่อ key แทนคำแปล
